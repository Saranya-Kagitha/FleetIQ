# FleetIQ
FleetIQ is an AI-powered vehicle safety system designed to detect bus overload and identify highway hazards to improve road safety.

FleetIQ is an AI-powered vehicle safety system designed to improve road safety by addressing two important challenges:

- 🚌 Bus overload detection
- 🛣️ Highway hazard detection

## Problem

Overloaded buses can affect vehicle stability and braking performance. At the same time, stationary vehicles on highways can create serious collision risks, especially when approaching drivers fail to notice them in time.

## Proposed Solution

FleetIQ combines sensor-based monitoring and AI-powered visual detection to provide timely safety alerts.

### 1. Bus Overload Detection
Sensors monitor the overall weight of the bus. When the detected weight crosses the defined safety threshold, the system alerts the driver using visual and audio warnings.

### 2. Highway Safety Assistance

FleetIQ explores an AI-assisted highway safety system that monitors road conditions and provides timely alerts when a potential collision risk is identified.

The proposed system focuses on combining vehicle detection, approaching-vehicle monitoring, driver alerts, and emergency-location support into a unified safety workflow.

## Key Features

- Real-time bus overload monitoring
- Visual and audio alerts
- AI-based vehicle detection
- Highway collision-risk alerts
- Potential integration with GPS and emergency services
